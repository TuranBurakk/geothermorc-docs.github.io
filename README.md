2. **Branch:** `master` → **`/ (root)`**
3. Save → wait ~1 minute → open the URL above

**Option B — GitHub Actions**

1. **Build and deployment → Source:** GitHub Actions
2. **Actions** → **Deploy GitHub Pages** → wait for green check
3. Open the URL above
